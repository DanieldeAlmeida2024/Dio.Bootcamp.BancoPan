# Guia para agentes de programação

Projeto: Dio.Bootcamp.BancoPan. Objetivo: Coleção de exercícios e laboratórios Java do bootcamp Banco PAN da DIO, com módulos Spring Boot, segurança e persistência.

Stack: Java, Spring Boot, Maven; projetos independentes em subpastas.

1. Consulte README.md, docs/REQUISITOS.md e docs/ARQUITETURA.md antes de editar.
2. Preserve autoria dos exercícios e os nomes dos módulos legados.
3. Prefira termos de domínio em português para novos artefatos, sem renomear APIs existentes por estética.
4. Acrescente testes JUnit para mudanças de comportamento Java; não afirme que executou Maven sem evidências.
5. Não versionar credenciais nem dados sensíveis.
6. Restrição atual: Este repositório é uma coleção de exercícios: não há um único comando para executar todos os exemplos.
