# Requisitos

## Objetivo
Coleção de exercícios e laboratórios Java do bootcamp Banco PAN da DIO, com módulos Spring Boot, segurança e persistência.

## Funcionais
- RF01: executar os exemplos de domínio previstos no exercício.
- RF02: oferecer saída verificável para dados válidos.
- RF03: representar erros de dados e integração de modo claro.

## Não funcionais
- RNF01: respeitar encapsulamento e responsabilidade única.
- RNF02: isolar persistência/infraestrutura do domínio quando aplicável.
- RNF03: não versionar credenciais.

## Fora do escopo
Este repositório é uma coleção de exercícios: não há um único comando para executar todos os exemplos.

**Observação:** escopo obtido da base didática disponível; ainda precisa de confirmação em execução.
